# Hardware

This directory contains all hardware-related files for the Wideband LNA project.

- `kicad/`: KiCad project files (schematics, PCB, etc.)
- `footprints/`: Custom KiCad footprints
- `datasheets/`: Datasheets for components used

# Wideband-LNA
LNA with Qorvo TQP3M9037
~20 dB gain
~0.5 dB noise figure
50 MHz to 3 GHz, or higher

Includes bias T option

power to +15V with internal low noise regulator
70 mA current draw at room temp

Input protection improved with inductor to ground.
Overdrive protection improved with 10 Ohm resistor in drain lead
